# Slay69

Slay69 is a command-line task manager written in Java 25. Add to-dos, deadlines, and events; search your tasks; and track what you have completed.

See the [User Guide](docs/README.md) for commands and examples.

## Run from source

Open this project in IntelliJ IDEA, set the project SDK to Java 25, and run the `main` method in `src/main/java/slay69/Slay69.java`.

## Run a release

Download the JAR from the latest GitHub release and run `java -jar Slay69.jar` in a terminal, replacing the filename if necessary. Slay69 saves tasks in `data/slay69.txt` relative to the folder where you run it.
